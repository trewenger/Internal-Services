1. System Overview

The Digital Signage Manager controls what is displayed on internal display boards. Content is added to Slideshows, and multiple can be defined at once. It has two main content types: images and videos and Google Sheet Resources (live snapshots of Google Sheets rendered as images). Both types can be attached to a slideshow that handles displaying the content.

Key Features:

  • Upload and manage a shared media library (images and videos)
  • Create multiple slideshows, each with its own media selection and slide speed
  • Each slideshow gets its own URL endpoint, so you can control what displays are viewing which slideshow
  • Dedicated per-slideshow preview pages that poll for live updates
  • Connect Google Sheets and have them auto-refresh as PNG images on a set interval
  • Sheet images can be included in slideshows alongside regular media

2. Media Library

The media library is a shared pool of files available to all slideshows. Upload images or videos here first, then assign them to individual slideshows.

Uploading Files

1

In the Media Library section, click Upload Media.

2

Select one or more image or video files. Multiple files can be uploaded in a single selection.

3

Uploaded files appear in the library and are immediately available to add to any slideshow.

Deleting Files

Click the delete icon on any media item. The file is removed from the library and automatically removed from any slideshow it was assigned to.

Note: Only supported image and video file types can be uploaded. Unsupported file types will be rejected with an error.

3. Slideshows

A slideshow is a named, ordered collection of media items that cycles automatically on the preview page. You can have multiple slideshows and point different displays at different preview URLs.

Creating a Slideshow

1

Click + New Slideshow.

2

Enter a name, an optional description, and a slide speed in seconds (how long each slide is shown before advancing).

3

Click Create. The slideshow appears in the list, initially empty.

Managing Slideshow Content

Expand a slideshow card to manage its content:

  • Add media — select items from the media library and drag them into the slideshow card to include them. Sheet resource images can also be added here via the dropdown.
  • Remove media — click the remove icon on any assigned item to take it out of the slideshow (the file/resource stays in the library).
  • Slide speed — edit the seconds-per-slide setting and save.
  • Enable / Disable — a disabled slideshow's preview page will show a blank or waiting state.

Deleting a Slideshow

Click Delete on the slideshow card. This removes the slideshow configuration only — it does not delete any media files from the library.

4. Slideshow Preview Page

Each slideshow has a dedicated full-screen preview page at /signage/slideshow/<slideshow-name>. This is the URL you point a display board browser to.

Live Updates

The preview page polls the server periodically for changes to the slideshow's media list and settings. When you add or remove a slide in the manager, the display board picks it up automatically without needing to be refreshed.

Opening the Preview

Click the Preview link on any slideshow card to open its preview page in a new tab.

Tip: On the display board computer, open the preview URL in a full-screen browser window. Because the page polls for changes, you rarely need to touch the display itself after the initial setup.

5. Google Sheet Resources

A Sheet Resource connects a Google Sheet to the signage system. The sheet is exported as a PNG image on a configurable interval and stored on the server. That image can then be added to any slideshow like a regular media file — so your display boards can show live data from a spreadsheet.

Adding a Sheet Resource

1

In the Sheet Resources section, click + Add Sheet.

2

Fill in the required fields:

  • Name — a display label for this sheet resource.
  • Sheet ID — the long ID string from the Google Sheet URL (the part between /d/ and /edit).
  • Refresh Interval — how often (in minutes) the PNG should be regenerated from the live sheet.
3

Optionally configure additional export settings: sheet tab (GID), portrait orientation, fit to width, hide gridlines, or a specific cell range to export.

4

Click Save. The system fetches and renders the sheet immediately. The image is then refreshed automatically at the configured interval.

Manual Refresh

Click Refresh Now on a sheet card to immediately re-fetch and re-render the sheet outside the normal schedule. Useful after making changes to the spreadsheet that you want to appear on the display right away.

Adding a Sheet to a Slideshow

Once a Sheet Resource exists, add it via the dropdown in the slideshow media settings.

Deleting a Sheet Resource

Click Delete on the sheet card. The resource is removed, its cached PNG is deleted, and it is automatically removed from any slideshows that included it.

Note: Sheet resources require the server's Google service account to have at least Viewer access to the spreadsheet. If the refresh fails, the last successfully rendered image remains in the slideshow until a successful refresh occurs. Adding sheet resources is a complex process, be sure you understand what you are doing and test often.
