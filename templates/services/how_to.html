1. System Overview

Various Services is a dashboard for running and scheduling internal automation scripts. Each service may connect tp Fishbowl, Google Sheets, Microsoft Apps, or Avalara to pull data, run checks, and push updates automatically on a configurable schedule.

Key Features:

  • One-click manual runs from the dashboard
  • Flexible scheduling: interval, daily, weekly, or custom cron
  • Per-service email notifications on success, failure, or both
  • Separate error and audit log panels per service
  • Live status badges and next-run times

2. Available Services

On-Time Performance

Queries Fishbowl for order completion data and updates the On-Time Performance Google Sheet.

Tax System Health

Checks Fishbowl for tax compliance issues — specifically product tax codes and customer exempt statuses.

Vendor Tracker

Finds parts currently at vendor via Fishbowl and updates the Vendor Tracker Google Sheet.

WIP Update

Updates the WIP Tracker Google Sheet with current work-in-progress data from Fishbowl.

3. Running a Service

Any service can be run immediately using the ▶ Run Now button, regardless of its schedule or whether scheduling is enabled.

1

Click ▶ Run Now on the service card.

2

The status badge changes to Running... while the service executes.

3

When complete, the badge updates to Last run: Success or Last run: Error.

Note: A service cannot be run again while it is already running. The Run Now button will be disabled until the current run completes.

4. Scheduling

Open a service card and click the Schedule tab to configure automatic runs. Toggle Scheduled on to reveal the scheduling options.

Every N Minutes

Runs the service repeatedly at a fixed minute interval. The interval is anchored to the last run time, so restarting the server will not reset the clock.

Daily

Runs once per day at a chosen time. If the scheduled time is missed (e.g., server is down), the next run will be the following day at that time.

Weekly

Runs once per week on a chosen day and time.

Custom (Cron)

Enter a standard cron expression for full control over the schedule. Format: minute hour day month day_of_week. Example: 0 9 * * 1-5 = Mon–Fri at 9:00 AM.

Tip: Click Save Schedule after making any changes. The Next: time in the card header will update immediately to confirm the new schedule was applied.

5. Notifications

Open a service card and click the Notifications tab to configure email alerts.

Notify Me Options:

  • Off No emails are sent.
  • After every run An email is sent after every run, whether it succeeded or failed.
  • On failures An email is only sent when a run encounters an error.

Managing Recipients:

Add email addresses one at a time using the Recipients field and click + Add (or press Enter). Remove any recipient by clicking the × on their chip.

Note: Notification emails include the run status, timestamp, and a full log table so you can see exactly what the service did.

6. Logs & Run History

Open a service card and click the Logs tab to view run history. Two panels are shown: Recent Errors and Recent Logs.

Recent Errors

Shows only runs that encountered an error, including a breakdown of what failed. Up to 10 entries are kept.

Recent Logs

Shows successful runs with the full log output from that run. Up to 10 entries are kept.

Buttons:

  • Refresh — reloads the log panel from the server.
  • Clear All — permanently deletes the log history for that panel.
Tip: Logs are loaded on demand when you open the Logs tab. Use Refresh if a run just completed and you want to see the latest entry.
