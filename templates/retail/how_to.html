1. System Overview

The Retail Inventory Manager is a webapp/web-tool that controls inventory levels in Fishbowl (Retail Website Inventory Location), which is then used to control available inventory on e-commerce site.

Key Features:

  • Manual and Automated inventory management modes
  • Real-time synchronization with Fishbowl
  • Sales order tracking and quantity updates
  • SKU management with search functionality
  • Error logging and email notifications

2. Inventory Modes

Manual Mode

In Manual mode, you have full control over inventory quantities.

Use Case: When you want to limit or inflate website inventory to specific quantities (e.g., Black Friday sales).

Automated Mode

In Automated mode, the system automatically syncs inventory quantities in Fishbowl's "Retail Website Inventory" location for all SKUs.

Use Case: When you want the website to always reflect current Fishbowl inventory levels without manual intervention.

Switching Modes:

Use the toggle switch in the header to switch between Manual and Automated modes.

4. Editing & Deleting SKUs

Editing a SKU:

Click the "Edit" button next to any SKU, update fields, and click "Save".

Deleting a SKU:

Click the "Delete" button and confirm the deletion.

Tip: Color-coded quantities:
  • Red = Sold out (0)
  • Yellow = Low stock (1-10)
  • Green = In stock (11+)

5. Sync Functionality

The Sync process updates the "Retail Website Inventory" location in Fishbowl with current available quantities.

Automatic Syncing:

The system automatically syncs at the set interval (default: 5 minutes). Applies to both modes.

Manual Syncing:

Click "Sync Now" in Settings to trigger an immediate sync.

6. Sales Check (Manual Mode Only)

Monitors Fishbowl for new sales orders and decrements available quantities accordingly.

Note: In Manual Mode, both Sales Check and Sync run automatically.

7. Settings

Sync Interval:

  • Default: 5 minutes | Range: 1-180 minutes
  • Changes apply immediately without server restart
Warning: Values outside 3-5 minutes may cause unexpected behavior.

8. Error & Logging Management

The system logs all errors and actions. New errors automatically trigger email notifications.

Viewing Errors & Logs:

Expand the Settings panel to see the "Recent Errors" and "Recent Logs" sections.

Auto Refresh: The logs automatically refresh every minute.

Important Notes

  • Serialized Products: If you override the qty for a serialized product in Manual Mode, set it back to >= 100 and resync before switching to Automated Mode.
  • Authentication: All pages require login. Sessions will timeout after inactivity.
