1. System Overview

The Retail Promo Manager creates and schedules promotional discount codes in Fishbowl. You define a promo code, a discount amount, and a start and end window. The system automatically activates the discount in Fishbowl at the start time and deactivates it at the end time — no manual intervention required once the promo is saved.

Key Features:

  • Automatic activation and deactivation via a scheduled date trigger
  • Percentage or flat-amount discount types
  • Startup recovery — missed activations or expirations are caught on server restart
  • Full activity log per promo code

2. Promo Statuses

Every promo code is always in one of three states:

Pending

The promo has been created and registered in Fishbowl but the start datetime has not yet arrived. A scheduled job is waiting to activate it.

Active

The discount is live in Fishbowl. A scheduled job is waiting to deactivate it at the end datetime.

Inactive

The discount has been deactivated in Fishbowl. The window has passed or the promo was manually inactivated. No scheduled job is running.

3. Adding a Promo Code

1

Click + Add Promo to open the add modal.

2

Fill in all required fields:

  • Promo Code Name — the exact code that will be created in Fishbowl. Must be unique across both the system and Fishbowl.
  • Description — a label for internal reference.
  • Start Date & Time — when the discount should activate (PST).
  • End Date & Time — when the discount should deactivate (PST). Must be in the future and after the start time.
  • Discount Type — Percentage (e.g. 10%) or Flat Amount (e.g. $5 off).
  • Discount Amount — the numeric value. Percentages must be between 1 and 100.
3

Click Save. The system registers the discount in Fishbowl first — if that call fails, the promo is not saved.

Tip: If the start time has already passed when you save the promo, it will activate immediately rather than waiting.

4. Editing a Promo Code

Click the Edit button on any promo row to open the edit modal. The promo code name cannot be changed — all other fields can be updated.

Editing a Pending promo

The promo is reset to Pending and rescheduled at the new start datetime. If the new start has already passed, it activates immediately.

Editing an Active promo

The updated discount values are synced to Fishbowl immediately and the deactivation job is rescheduled at the new end time. If the new end time is in the past, the promo deactivates immediately.

Editing an Inactive promo

The promo is reset to Pending and re-evaluated against the new window. If the window has already passed, it stays Inactive.

Note: The end datetime must always be in the future and occur after the start date at the time of saving.

5. Manually Inactivating a Promo

To end a promo before its scheduled end time, click the Inactivate button on the promo row. The system immediately deactivates the discount in Fishbowl and cancels the scheduled deactivation job.

Note: The Inactivate button is only shown for Pending and Active promos. Already-inactive promos have no button.

6. How the Scheduler Works

The Promo Manager uses date triggers — one-shot scheduled jobs that fire at a specific datetime rather than on a recurring interval.

Pending promo

A job is scheduled to fire at the start datetime. When it fires, the discount is activated in Fishbowl and a second job is immediately created to fire at the end datetime.

Active promo

A job is scheduled to fire at the end datetime. When it fires, the discount is deactivated in Fishbowl and no further jobs are created.

Server restart recovery

On startup, the system checks every promo against the current time. Any promo whose start or end window was missed while the server was down is handled immediately — activations that were missed are fired, and expirations that were missed are applied. You do not need to manually fix anything after a restart.

The "Next Run" column in the promo table shows when the next scheduled job will fire for each promo. If a promo is Inactive, no job is scheduled and this column is blank.

7. Logs & Errors

The log panel at the bottom of the page tracks every action taken on every promo — creations, activations, deactivations, edits, and failures — along with who or what triggered the action (a user or the scheduler).

Recent Errors

Entries where a Fishbowl call failed or the promo could not be processed. Check here first when a promo does not activate or deactivate as expected.

Recent Logs

All activity, including successful activations and deactivations. Each entry shows the promo name, action type, triggered-by, result, and a description of what happened.

Tip: Use the Refresh button to reload logs after a recent action. Use Clear All to permanently delete log history from the respective panel.
